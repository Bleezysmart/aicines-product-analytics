# Reports

This folder contains the recruiter-facing and detailed analytical reports for the AICines Product Analytics case study.

## Reports

- `AICines_Product_Analytics_Short_Report.pdf` — concise recruiter-friendly summary covering the objective, synthetic-data disclosure, methodology, key findings, recommendations and conclusion.
- `AICines_Product_Analytics_Full_Report.pdf` — detailed case-study documentation covering the analytical workflow, validation, findings, recommendations and limitations.

## Data disclosure

Both reports clearly state that the operational dataset used in the case study is synthetic. AICines internal operational data was not publicly available.

The modeled figures are portfolio outputs and must not be interpreted as actual AICines business performance.
