# Reports

This folder contains the recruiter-facing and detailed analytical reports for the AICines Product Analytics case study.

## Reports

- **Short Report** — concise, recruiter-friendly summary covering the objective, data disclosure, methodology, key findings, recommendations and conclusion.
- **Full Report** — detailed case-study documentation covering the analytical workflow, validation, findings, recommendations and limitations.

## Data disclosure

Both reports clearly state that the operational dataset used in the case study is synthetic. AICines internal operational data was not publicly available.
